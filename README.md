# Doe+

Portal informativo sobre doação de sangue com encaminhamento direto para os hemocentros oficiais.

## Estrutura de páginas e rotas

- `/` (`index.html`) — Página inicial, requisitos principais, compatibilidade sanguínea e links diretos para hemocentros.
- `/sobre` (`sobre/index.html`) — Propósito do projeto e autoria.
- `/como-doar` (`como-doar/index.html`) — Guia completo do doador, etapas no hemocentro e perguntas frequentes.
- `/contato` (`contato/index.html`) — Canais oficiais dos hemocentros e redes do desenvolvedor.

## Como executar localmente

1. Extraia o projeto mantendo a estrutura de pastas.
2. Abra a pasta `Projeto-Doe` no VS Code.
3. Inicie o servidor local com a extensão **Live Server** a partir de `index.html`.

## Propósito

O Doe+ é um projeto estritamente informativo desenvolvido originalmente no contexto acadêmico de TIAW (Trabalho Interdisciplinar: Aplicações Web) e refinado para apresentar orientações claras sobre doação de sangue e encaminhar visitantes diretamente aos portais oficiais dos hemocentros.

## Limitações importantes

Este repositório contém somente o front-end estático. Não há servidor, banco de dados, autenticação ou sistema próprio de agendamento.

O Doe+ é um projeto educativo, não um serviço de saúde. Os critérios de doação podem depender de avaliação individual e de atualizações nas normas. A equipe do hemocentro é responsável pela triagem e pela orientação final.
